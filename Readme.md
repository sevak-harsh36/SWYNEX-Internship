# Student Performance Analysis and Data Preprocessing

## Project Overview

This project focuses on analyzing student performance data and preparing the dataset for machine learning.

## Objectives

* Perform Exploratory Data Analysis (EDA)
* Identify and handle missing values
* Detect and remove duplicate records
* Encode categorical variables
* Analyze relationships between student performance features
* Split data into training and testing sets
* Scale numerical features
* Prepare the dataset for machine learning

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

## Dataset

The project uses a student performance dataset containing academic scores and demographic/educational information.

## Project Workflow

Dataset → Data Cleaning → EDA → Missing Value Handling → Encoding → Feature Preparation → Train-Test Split → Feature Scaling

## Result

The dataset was successfully cleaned and transformed into a machine-learning-ready format.
